### 🚧 What I'm working on

**[CookTree](https://github.com/aliccee/cooktree-webmcp)**: agent-native meal planning over WebMCP *(hackathon, with [@aliccee](https://github.com/aliccee) and [@ReddWu](https://github.com/ReddWu))*
> The site's UI and the AI agent call the same tool layer, so anything a person can click, an agent can do too.

**[EveryoneAtOnce](https://eao.nathanchengyi.com)**: which character are you, answered with real statistics ([source](https://github.com/NathanCheng685/everyone-at-once))
> Simulation-based inference over LLM-generated personas. A local model role-plays every character answering each question, the answers become likelihood tables, and visitors get a tempered posterior instead of a hand-made quiz score. Six story worlds, English and Chinese.

**[Quota Blocks](https://github.com/NathanCheng685/quota-blocks)**: see your remaining ChatGPT / Codex and Claude quotas at a glance
> macOS menu bar and Windows taskbar app. Runs locally, no server, no telemetry. C# on both platforms.

**[SmartCited](https://smartcited.com)**: AI-visibility actions for local businesses ([demo](https://smartcited.com/#/scan/sample) · [Devpost](https://devpost.com/software/smartcited) · [source](https://github.com/ReddWu/Cited))
> Submitted to OpenAI Build Week. Runs leakage-checked local-discovery questions through OpenAI and Gemini, preserves citation evidence, and turns it into customer-authorized website, Yelp, and directory actions.

**[mylit.net](https://github.com/iccontre/mylit.net)**: sleep and productivity app, with [@iccontre](https://github.com/iccontre)
> React Native + Expo Router. Onboarding, journaling, dream journal, morning intention, sleep check-in, weekly summary, and an awareness/quest pipeline.

**[VStandby Studio](https://github.com/srbisupermeni/4-26hack)**: AI live companion for sports and esports viewers *(4/26 Hackathon)*
